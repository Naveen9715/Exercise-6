# 📍 Android GPS Location Tracker (Exercise 6)

An Android application demonstrating real-time GPS geolocation tracking, Location Services, and Android runtime permission management.

## 📱 Features

- **GPS Location Tracking**: Integrates Android LocationManager and LocationListener to retrieve accurate geographic coordinates.
- **Runtime Permissions**: Implements permission checks and requests for ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION.
- **Real-Time Coordinates**: Displays current Latitude, Longitude, and positional accuracy on screen.
- **Provider Management**: Gracefully handles GPS and Network provider status changes.

## 🛠️ Built With

- **Language**: Java
- **Platform**: Android
- **APIs**: Android Location Services (ndroid.location.LocationManager)
- **Permissions**: Fine & Coarse Location Access
